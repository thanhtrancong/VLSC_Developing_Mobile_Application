# 📱 Lập Trình Ứng Dụng Di Động Tích Hợp AI

Repository lưu trữ các bài thực hành (Lab) môn **Lập trình Ứng dụng Di động Tích hợp AI**.

---

## 🏫 Thông Tin Học Phần

- **Trường:** Cao đẳng Văn Lang Sài Gòn (VLSC)
- **Khoa:** Công nghệ Sáng tạo
- **Chuyên ngành:** Ứng dụng Phần mềm
- **Môn học:** Lập trình Ứng dụng Di động Tích hợp AI

---

## 🌿 Quy Tắc Quản Lý Nhánh (Branch Strategy)

Dự án được quản lý theo quy định: **Mỗi bài Lab được phát triển và lưu trữ trên 1 nhánh (branch) riêng biệt.**

- `main`: Nhánh chính chứa dự án mẫu / mã nguồn tổng hợp.
- `lab-01`: Bài thực hành Lab 01.
- `lab-02`: Bài thực hành Lab 02.
- `lab-...`: Các bài thực hành tiếp theo.

### 🛠️ Hướng Dẫn Thao Tác Với Nhánh

```bash
# Xem danh sách các nhánh
git branch -a

# Tạo và chuyển sang nhánh bài lab mới (Ví dụ: lab-01)
git checkout -b lab-01

# Chuyển đổi giữa các nhánh bài lab
git checkout <tên-nhánh>

# Đẩy nhánh lab lên GitHub
git push origin <tên-nhánh>
```
